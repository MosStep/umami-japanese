# รีวิว うまみ และแผนพัฒนา

## 1) จุดอ่อน 5 ข้อที่ทำลาย retention ของผู้เรียนไทย

1. **ข้อมูลอยู่แค่ใน localStorage** — เปลี่ยนเครื่อง/เคลียร์แคช = ความก้าวหน้าหายหมด ผู้ใช้ที่ลงทุนเรียนมา 1 เดือนจะไม่กลับมาอีก นี่คือข้อบกพร่องร้ายแรงสุด ต้องแก้ก่อนทุกอย่าง
2. **ไม่มี onboarding / placement** — เปิดมาเจอ 98 คลิป N5–N1 กับ deck 138 คำที่ไม่ใช่ของฉัน ผู้ใช้ใหม่ไม่รู้ว่าควรเริ่มตรงไหนและ "รู้ X%" ยังเป็น 0% ทุกใบ
3. **สัญญาณความก้าวหน้าปลอม** — streak = แค่เปิดแอป, XP มาจากการดูเฉยๆ, เป้า 10 นาทีวัดเวลาไม่ใช่การเรียนรู้ ระบบให้รางวัลพฤติกรรมที่ไม่ทำให้เก่งขึ้น
4. **ไม่มีการเรียกกลับ** — ไม่มี notification เลย แอปเรียนภาษาที่พึ่งความจำของผู้ใช้ในการกลับมา จะตายภายใน 3 วัน
5. **ดู กับ ฝึก ไม่เชื่อมกัน** — ดูจบคลิปแล้วไม่มีอะไรเกิดขึ้น ไม่มี quiz หลังดู คำศัพท์ไม่ไหลเข้า deck อัตโนมัติ และซับอนิเมะที่ฟังผิดบั่นทอนความไว้ใจในส่วนที่ดึงดูดที่สุด

## 2) Roadmap 3 รีลีส

### R1 — "ไม่หาย ไม่ลืม" (รากฐาน retention)
- **Backup/Restore** (S): ปุ่ม export JSON → แชร์ไป Google Drive/LINE Keep ผ่าน Capacitor Share + import กลับ; สำรองอัตโนมัติทุกวันลง Filesystem ของเครื่อง
- **Local notifications** (M, ต้อง APK): "มี 12 คำรอทบทวน" เวลาที่ผู้ใช้เลือก, ไม่ต้องมี server ใช้ `@capacitor/local-notifications`
- **Onboarding 90 วินาที** (S): เลือกเป้า → เช็ก 20 คำ "รู้/ไม่รู้" (เรียงตามความถี่) → ประมาณระดับ → เปิดคลิปแรกให้เลย
- **นิยาม streak ใหม่** (S): นับเมื่อ "ดูจบ ≥15 บรรทัด หรือ ทบทวน ≥10 ใบ" และเพิ่ม streak freeze 1 ครั้ง/สัปดาห์
- **การ์ด "วันนี้" บนหน้าฟีด** (S): คำที่ค้างทบทวน + 1 คลิปแนะนำ = จุดเริ่มเดียว ไม่ต้องคิด

**ทำไม:** ทุกข้อแก้เหตุผลหลักที่คนเลิกใช้ และทำได้ใน 2–3 สัปดาห์ด้วย agent

### R2 — "ดูแล้วติด" (ปิดลูปการเรียน)
- **Quiz ท้ายคลิป 5 ข้อ** (M): สร้าง offline จากข้อมูลที่มีอยู่แล้ว — ความหมายคำ, ฟังแล้วเลือกคำไทย, เรียงประโยค, cloze ไม่ต้องใช้ API
- **เก็บเกี่ยวคำอัตโนมัติ** (M): คำที่ปรากฏในคลิปที่ดูจบ ≥2 ครั้ง และยังไม่ "รู้" → เสนอเข้า deck (ผู้ใช้กดยืนยันทีเดียว)
- **แนะนำแบบ i+1** (S): แท็บ "พอดีตัว" = คลิปที่รู้ 85–95% แทน "เข้าใจง่าย" ≥60% ซึ่งหลวมเกินไป
- **โหมดดูรอบสอง** (S): ซ่อนไทยอัตโนมัติเมื่อดูซ้ำ + ติ๊ก "เข้าใจไหม" ต่อบรรทัด → ป้อนข้อมูลกลับมาปรับระดับ
- **ปุ่มรายงานซับผิด** (S): เก็บ log ใน localStorage, export รวมไปในไฟล์ backup เพื่อให้ agent แก้เป็นชุด

### R3 — "พูดออกมา" (output)
- **Shadowing ในเพลเยอร์** (M): กดค้างบรรทัดใดก็ได้ → อัด → คะแนน ไม่ต้องไปแท็บ Dojo
- **แปลไทย→ญี่ปุ่น พูดเอง** (M): จาก saved sentences ใช้ speech recognition แล้วเทียบ token
- **Weekly recap เป็นรูปภาพ** (S): แชร์ไป LINE/IG story — การตลาดฟรี
- **เสียงจิ้งจอกมีสถานะ** (S): เปลี่ยนตามความสม่ำเสมอ ไม่ใช่แค่ประโยคสุ่ม

## 3) ปรับตามหลัก learning science

- **SRS**: ช่วงเวลา 1/2/4/8 ตายตัวไม่ดี เปลี่ยนเป็น ease factor ต่อใบ (เริ่ม 2.5 ลดเมื่อ again) และ **จำกัดทบทวน 40 ใบ/วัน** ป้องกันกองดอง — สาเหตุอันดับหนึ่งที่คนเลิกทำ Anki
- **เรียงคำใหม่ตาม ความถี่ใน corpus × ปรากฏในคลิปที่กำลังจะดู** → "สอนก่อนดู" 5 คำ แล้วค่อยเปิดคลิป ผู้เรียนจะรู้สึกว่าเข้าใจทันที (ทรงพลังมาก)
- **Comprehensible input**: บังคับเพดาน — ผู้ใช้ N5 เห็นคลิป N2 ได้แต่มีป้ายเตือน "รู้แค่ 40%" ไม่ใช่ซ่อน
- **Generation effect**: ก่อนโชว์ "อธิบายประโยค" ให้เดาความหมายก่อน 1 แตะ (เลือก 2 ตัวเลือก) แล้วค่อยเฉลย
- **Narrow listening**: จัดเป็น "ซีรีส์" ช่องเดียวกัน 3–5 ตอน คำซ้ำสูง เรียนเร็วกว่าสุ่มข้ามหมวด
- **Output**: shadowing ที่มีอยู่ดีแล้ว แต่ต้องอยู่ใน

**Output:** shadowing ที่มีอยู่ดีแล้ว แต่ต้องอยู่ใน flow ของ player ไม่ใช่แยกใน Dojo — ปุ่ม "พูดตามประโยคนี้" ใต้ซับทุกบรรทัด ให้ผู้ใช้พูดได้ทันทีตอนยังอินกับฉาก และเพิ่มขั้น "แปลกลับ" (เห็นไทย → พูด/พิมพ์ญี่ปุ่น) ใน saved-sentence deck เป็น output ที่ถูกที่สุด ไม่ต้องใช้ API เลย AI roleplay ยังไม่คุ้มพัฒนาต่อจนกว่าจะมี quota ที่นิ่ง ให้ซ่อนไว้หลัง "ทดลอง"

**คำศัพท์ที่ควร SRS:** อย่าปล่อยให้ deck เป็นแค่ 138 คำ + คำที่ผู้ใช้กด ให้ระบบเสนอ "คำที่เจอ ≥3 ครั้งในคลิปที่ดูแล้วแต่ยังไม่รู้" อัตโนมัติ (คำนวณจาก token ได้บนเครื่อง) นี่คือ i+1 ตัวจริงของแอปนี้ และเป็นจุดที่คู่แข่งอย่าง Anki ทำไม่ได้

## 4. Retention / แรงจูงใจ (ไม่ต้องมี backend)

**ควรทำ**
- **Streak ต้องมาจากการเรียน** ไม่ใช่แค่เปิดแอป: นับเมื่อดูจบ ≥1 ประโยคพร้อมเปิดคำ หรือทบทวน ≥5 การ์ด + มี "วันพัก" 1 วัน/สัปดาห์ (streak freeze) คนไทยเลิกแอปเพราะ streak ขาดแล้วรู้สึกเสียเปล่า
- **Local notification 1 ครั้ง/วัน** ผ่าน Capacitor plugin (ต้องออก APK) ข้อความสั้น เป็นมิตร: "จิ้งจอกรออยู่ 🦊 มี 8 คำรอทบทวน" เลือกเวลาได้เอง — ตัวเดียวที่เพิ่ม D7 retention ชัดที่สุด
- **เซสชัน 10 นาทีสำเร็จรูป** ปุ่มเดียวหน้า feed: ทบทวนการ์ดที่ถึงกำหนด → คลิปต่อ 3–5 ประโยค → พูดตาม 1 ประโยค → สรุปวันนี้ ลดการตัดสินใจ ซึ่งเป็นสาเหตุหลักที่คนเปิดแอปแล้วปิด
- **"สัปดาห์นี้คุณรู้คำเพิ่ม X คำ และเข้าใจคลิป Y% มากขึ้น"** — progress ที่จับต้องได้จาก known-word share ของคลิปที่เคยดู แสดงกราฟ 4 สัปดาห์ในหน้าฉัน ฟรี ไม่ต้องมีอะไรเพิ่ม
- **แชร์การ์ดภาพ** ประโยคโปรด + คำแปล + โลโก้แอป เป็น PNG ไป LINE/IG — ทั้ง motivation และช่องทางหาผู้ใช้ใหม่เดียวที่มีตอนนี้

**ไม่ควรทำ**
- Leaderboard/เพื่อน/ลีก — ไม่มี backend ทำปลอม ๆ ก็ไร้ความหมาย
- เหรียญ/ร้านค้า/ชุดแต่งมาสคอต — เสียเวลา dev มากกว่าผลที่ได้ในแอปที่มีผู้ใช้คนเดียว
- Badge เพิ่ม — 8 อันพอแล้ว เน้นให้ที่มีอยู่ปลดได้จริงภายใน 2 สัปดาห์แรก
- Social login/บัญชี — ยังไม่ถึงเวลา ใช้ export/import แทน
