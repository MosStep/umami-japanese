## 1.0.26 — ดูแล้วติด (OTA)

- 📝 แบบทดสอบท้ายคลิป 5 ข้อ: ความหมายคำ, ฟังแล้วเลือกความหมาย, แปลประโยค, เติมคำ, เรียงคำ ขึ้นเองเมื่อดูจบ หรือกดที่ท้ายรายการ "ประโยคทั้งหมด"
- ➕ คำใหม่จากคลิป: คำที่เจอบ่อยในคลิปหรือตอบผิด เลือกแล้วเพิ่มเข้าคลังฝึกได้ในแตะเดียว
- 🎯 ตัวกรอง "พอดีตัว" (แทน "เข้าใจง่าย"): คลิปที่รู้คำ 80–95% ถ้ายังไม่มี จะแสดงคลิปที่ใกล้ที่สุด
- ✓ การ์ดคลิปบอกว่าดูจบแล้ว
- 👀 ดูรอบสอง: คลิปที่เคยดูจบจะซ่อนคำแปลให้อัตโนมัติ จบแล้วบอกว่าเข้าใจเองกี่ประโยค
- 🚩 แจ้งซับผิด: กด "อธิบายประโยค" แล้วกด "ซับประโยคนี้ผิด?" ส่งออกได้ที่ ⚙️ ตั้งค่า และติดไปกับไฟล์สำรองด้วย
- 📊 สรุป 7 วันล่าสุดในหน้า ฉัน (นาที, ทบทวน, คำใหม่, คลิปที่ดูจบ) แชร์เป็นรูปได้
- 🦊 จิ้งจอกมีอารมณ์ตามจำนวนวันที่เรียนในสัปดาห์
